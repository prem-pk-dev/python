# Playwright Visual Website Crawler\n\nRun GitHub Actions workflow Visual Website Crawler (Playwright). Inputs: public URL, 1–100 pages per run, desktop/mobile/all viewports, full/viewport/both screenshots.\n\nArtifacts include screenshots/, crawl-report.json and pages.csv. Artifacts are retained for 7 days. Each run is capped at 100 pages and 45 minutes. GitHub Actions usage and artifact storage quotas apply. It follows same-origin links and does not bypass login, paywalls, CAPTCHAs or anti-bot restrictions. Crawl only sites you own or are authorized to inspect; respect site terms and robots policies.\n\nThe existing Hacker News workflow is separate and unchanged.\n
